# 4XGAME

A small multiplayer game-lobby demo using **virtual coins only**.

> This repository intentionally does not implement real-money deposits, withdrawals, cash prizes, betting, or payment processing. Virtual coins have no monetary value.

## Run locally

Requires Node.js 18+.

```bash
npm install
npm start
```

Open http://localhost:3000.

## Included

- Registration and login demo
- Virtual wallet with starter/demo coins
- Match creation and joining
- Server-side balance checks
- Match prize pool in virtual coins
- Demo-only result endpoint
- Transaction history data model

## Important production notes

This is an in-memory demo and is not production-ready: data resets when the server restarts, authentication is intentionally minimal, and game results are not yet generated by a real server-authoritative Ludo engine. Before any public launch, add persistent storage, secure authentication, authorization, anti-cheat controls, validation, rate limits, tests, monitoring, and legal review. Do not add cash wagering or payment flows without qualified legal/compliance approval and all required licenses.
